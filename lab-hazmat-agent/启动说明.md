# 启动说明

> 当前实际可用的启动方式（2026-10-17 实测通过）。Python 依赖统一装在 conda 环境 `agent`（`G:\Anaconda3\envs\agent`，Python 3.11.17），不另建 venv。

## 0. 前置条件

> **最省事的方式**：直接双击仓库根目录的 `启动.bat`，它会开两个命令行窗口分别拉起前后端（首次会自动补装前端依赖）。下面的命令适合手动排查时逐条执行。

| 项 | 要求 | 当前状态 |
|---|---|---|
| Python 环境 | conda `agent` 环境，16 个依赖齐全 | ✅ 就绪 |
| MySQL | 8.0（本项目接的是腾讯云 CDB） | ✅ 已连通，12 张表有数据 |
| 大模型 API Key | DashScope `sk-` 真实密钥 | ❌ 当前是占位符 `sk-x...`，需替换 |
| 前端依赖 | `node_modules`（npm 安装，非 conda 管理） | ✅ 已安装 140 个包 |

> 大模型 Key 写在 `lab-hazmat-agent/.env` 的 `LLM_API_KEY`，替换后需重启后端。

## 1. 启动后端

**必须在 `lab-hazmat-agent/` 目录下启动**——`.env` 和 `CHROMA_DIR=./corpus/chroma` 都是相对当前工作目录解析的，在 `backend/` 里启动会读不到配置（会退回 `mysql` 主机名等默认值）。

```bash
cd G:/AI0707/lab_agent/lab-hazmat-agent
PYTHONPATH=backend G:/Anaconda3/envs/agent/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

验证：

```bash
curl http://127.0.0.1:8000/api/health
# 期望：{"status":"ok","mysql":true}
```

接口文档：http://127.0.0.1:8000/docs

## 2. 启动前端

```bash
cd G:/AI0707/lab_agent/frontend
npm run dev
```

访问：http://127.0.0.1:5173

前端有两种数据模式，由 `frontend/.env` 的 `VITE_API_MODE` 控制：

| 值 | 含义 |
|---|---|
| `backend`（当前） | 走 `/api/data/*` 真实接口，数据来自 MySQL；首屏会显示「实时数据库」徽标与读取时间 |
| `mock` | 全部用本地模拟数据（`src/mocks/labData.ts`），不请求后端 |

切换后需重启前端。**`backend` 模式下若后端未启动，页面会显示「连接失败」并说明原因，不会静默回落到演示数据。**

## 3. 数据接口（只读）

后端在 `/api/data` 下提供控制台所需的领域数据，全部是固化的 SELECT，字段已转成前端驼峰命名：

| 接口 | 内容 |
|---|---|
| `GET /api/data/overview` | 首屏聚合：9 个数据集一次返回（前端 store 用这个） |
| `GET /api/data/labs` | 实验室 |
| `GET /api/data/persons` | 人员 |
| `GET /api/data/qualifications` | 资质 |
| `GET /api/data/authorizations` | 实验室授权 |
| `GET /api/data/access-events?limit=200` | 门禁记录 |
| `GET /api/data/inventory` | 药剂台账 |
| `GET /api/data/hazmat-uses` | 领用记录 |
| `GET /api/data/equipment` | 设备台账 |
| `GET /api/data/equipment-loans` | 设备借还 |

> 与 Agent 工具层的区别：工具层面向大模型，剧毒品/易制爆数量做区间化脱敏；本接口面向管理控制台，返回完整数字，但同样只读。

## 5. 已知问题

### 普通提问返回 500：`invalid_api_key`

后端日志里是 `401 Unauthorized`，`LLM_API_KEY` 仍是占位符。这不是代码问题——控制类拦截（如"帮我把某人资质改到明年"）不经过大模型，能正常返回拒绝话术；只有需要大模型推理的问答会失败。

**修复**：把真实 DashScope Key 填进 `lab-hazmat-agent/.env` 的 `LLM_API_KEY`，重启后端。同时需要重跑 `app.rag.ingest` 建索引，否则规程检索为空。

### 端口被占用

```bash
# Windows 查占用进程
netstat -ano | findstr :8000
taskkill /PID <PID> /F
```

### 为什么不用 `cd backend && uvicorn app.main:app`

`config.py` 里 `env_file=".env"` 是相对 CWD 的。`.env` 放在 `lab-hazmat-agent/` 根目录，所以必须在项目根启动，并用 `PYTHONPATH=backend` 让 `app` 包可导入。
